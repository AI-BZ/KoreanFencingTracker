## 0. 국가대표 선발 (성인 — 확정, 협회 규정 원문 기준)

**근거**: 대한펜싱협회 「국가대표 선발 규정」 2025.04.23 개정 (협회 공지 boardNo=10479 첨부 원문 확인).
**구현**: `ranking/national_team.py` → 랭킹 페이지 "국가대표" 섹션, 프로필 "국가대표 선발 포인트" 카드, `/api/rankings?age_group=NT`.
**정답지**: 협회 공지판 「N년 국가대표 선발을 위한 4개 대회 합산 점수 및 랭킹 현황」 (2024 boardNo=10303, 2025 최종 10578, 2026 8/5 10898·8/26 10916), 선발 명단 (2024 10310, 2025 10576).

| 제20조 ③ | 동점: 4개 대회 중 1위 많은 순 → 2위 … ; 전부 같으면 대통령배→김창환배→종목별오픈→국대선발 성적 순 | `_sort_key` — 점수 받은 순위 목록 사전식 비교(협회 표 실측 확정), 이후 대회 순서 |
| 제21조 | 종목별 16명 = 입촌 8명(선발 순위) + 25세이하 후보 8명(최근 3년 세계청소년선수권 개인 입상자 최대 4명 우선) | 선발권 표시 상위 8 (2025 남녀 사브르 12 — 선발 명단 실측) |

**협회 표 특이점(우리도 동일하게 구현)**: 아직 열리지 않은 대회 칸에 **직전 연도 같은 대회**를 넣어 합산한다 (2026.08.26 표의 김창환배 칸 = 2025 김창환배; 2016.11.21 부칙 "차년도 선발 시 중복 적용"). 우리 표는 그 칸을 "2025 김창환배 · 직전 회차"로 표시하고 새 회차 결과가 들어오면 교체한다.

**검증 (2026-09-27, 2025 복구 후)**: 2025 최종표 총점 일치 97.6%(1,337/1,370), 6종목 상위 8/12 집합·순서 일치, 선발 명단 56명 협회 순위 정확 일치 56/56. 2026 8/26 표(2025 김창환배 이월) 98.5%(1,489/1,511), 6종목 상위 8 집합·순서 일치. 2023·2024 대통령배·종목별오픈은 DB에 개인전 이벤트가 없어 대조 불가.

## 2. 청소년 대표 선발 (육성 지원 프로그램)

### 기본 정보
- **대상**: 중2 ~ 고3 (선발 연도 기준 나이)
- **성격**: 선수 육성 지원 프로그램 (국가대표 선발과 별개)
- **선발 인원**: 종목·성별별 8명 (6종목 × 8명 = 48명)
- **산출 기준**: 전년도 성적 기반 (예: 2025년 성적 → 2026년 선발)
- **포인트**: ⚠️ 미확정 — 임시로 꿈나무 배점표 적용 중

### ⚠️ 검증 결과 (2026-09-27): 현재 포인트는 실제 청소년대표팀 명단을 재현하지 못한다
정답지: `data_kfa_rosters` youth/2025/media 48명(@untouche_fencing 2025 청소년대표선수 합숙훈련 게시물, 1차 2025.7.26~ 강진 — 종목·성별당 8명, 구성이 **고등 5 + 중등 3**으로 일정) — 이름 48명 전원 DB 존재.
- 국대 4개 대회(현재 코드) 포인트로 상위 8명: 2024 달력 3/48, 2024.07~2025.06 1/48, 2025.01~06 0/48, 2025 달력 1/48 → **기각**. 명단 대부분이 4개 대회에서 0~2점(중학생 다수).
- 중·고 대회 세트(꿈나무 5개 / +유소년 국대선발전 / 창 내 모든 중·고 개인전)로 32/26/20 배점 합산, 고5+중3 분할 쿼터: 최고 18/48(38%) — 어느 창·세트도 재현 못 함. 미재현자 중 고득점자(정윤경 86pt, 김하은 84pt 등) 다수 → 단순 합산 포인트 기준이 아니거나 미공개 요소(선발전·평가·추천) 개입.
- 협회 공지 10582(2025.09.19) 첨부의 "2025 청소년 대표선수 명단" 24명(종목·성별당 4명, 경남대·한체대 등 대학생 포함, seed_rank 5~41)은 **다른 명단**이다 — 2025 국가대표 4개 대회 합산 순위 중 (추정) 20세 이하 상위 4명. 인스타 48명(중2~고3 육성 스쿼드)과는 2명(김도하·정유준)만 겹친다(kfa-notices 기준; 그 2명은 kfa 행으로 저장돼 media 46행에는 없음).
- 협회 공지판·중고연맹 사이트·`data_kfa_notices`(youth 23건·kkumnamu 20건)에 청소년대표팀·꿈나무 **선발 기준 문서 없음**(지도자 채용·장비·특기장려금뿐).
→ 이 페이지의 포인트는 "국가대표 선발대회 4개 대회 기준 청소년(중2~고3) 순위"로만 읽어야 하며, 협회 청소년대표팀 선발과 다르다는 안내를 유지할 것. 대상 대회·배점은 여전히 미확정.

## 4. 데이터 오류 제보 시스템 (계획)

### Phase 1 — MVP (간단 제보 수집)
- footer 또는 각 페이지에 "오류 제보" 링크
- Google Form 또는 간단 API (`POST /api/feedback`)
- 제보 내용: 페이지 URL, 선수명, 잘못된 내용, 올바른 내용, 제보자 연락처(선택)
- DB 테이블: `data_feedback` (제보 저장)

### Phase 2 — 자동 검증
- 제보 수신 → 자동 검증 (DB 데이터 vs 제보 내용 비교)
- 검증 가능: 선수 소속, 대회 결과 순위, 점수
- 검증 불가: 동명이인 분리/병합 → 관리자 수동 확인

### Phase 3 — 관리자 승인 워크플로
- 관리자 대시보드: 제보 목록 + 자동 검증 결과
- 상태: 접수 → 검증중 → 승인대기 → 승인/반려
- 승인 시 자동 수정 반영 + 제보자 알림

### DB 테이블 설계 (계획)
```sql
CREATE TABLE data_feedback (
    id SERIAL PRIMARY KEY,
    page_url TEXT,
    category VARCHAR(50),  -- 'player_info', 'match_result', 'ranking', 'selection', 'other'
    player_name VARCHAR(100),
    description TEXT NOT NULL,
    expected_value TEXT,
    reporter_contact VARCHAR(200),
    status VARCHAR(20) DEFAULT 'pending',  -- pending, verified, approved, rejected, fixed
    admin_note TEXT,
    auto_check_result JSONB,
    created_at TIMESTAMPTZ DEFAULT NOW(),
    resolved_at TIMESTAMPTZ
);
```

### 면책/안내 문구 (구현 완료: 2026-04-21)
- **글로벌 (base.html footer)**: "본 서비스의 데이터는 자동 수집(스크래핑) 기반이며, 공식 기록과 다를 수 있습니다..."
- **선발 페이지 상단**: "⚠️ 본 순위는 공개된 대회 결과를 기반으로 추정한 비공식 자료입니다..."

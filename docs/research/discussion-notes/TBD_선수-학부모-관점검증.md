# 대회장에서 실제로 필요한 화면 — 선수·학부모 관점 검증

> 🔴 **미작성 (작성 필요).** 이 파일은 **빈 양식**이다.
> 현재 화면 구성은 개발자 판단으로 만들어졌고, **실제 대회장 사용 맥락에서 검증한 기록은 없다.**
> 아래 논점 질문으로 실제 대화를 나눈 뒤 채운다. 추측으로 채우지 않는다.

## 논점 질문 (답변란 비어 있음)

1. 대회 **당일 경기장에서** 휴대폰으로 확인하고 싶은 것은 무엇인가? 시간 순으로 짚어보면 — 도착 직후 / 풀 진행 중 / 풀 끝난 직후 / 토너먼트 대진 확정 후 각각 무엇이 궁금한가?
   -
2. 그중 **가장 급한 것 하나**만 고른다면? (예: 내 풀 순위, 다음 상대, 진출 여부, 대진표 위치)
   -
3. 다음 상대가 정해졌을 때 그 선수에 대해 무엇을 알고 싶은가? 과거 전적인가, 최근 성적인가, 아니면 아예 안 보는 편이 나은가?
   -
4. 학부모(관중석)와 선수(피스트)는 필요한 화면이 다른가? 다르다면 어떻게 다른가?
   -
5. 지금 만들어진 화면 중 **실제로는 안 쓰게 되는 것**이 있는가? 반대로 없어서 아쉬운 것은?

# 왜 만들기로 했는가 — 문제 정의

> 🔴 **미작성 (작성 필요).** 이 파일은 **빈 양식**이다.
> 박계진·박소윤 사이의 실제 논의 내용은 기록이 없어 비워 두었다.
> 아래 논점 질문을 길잡이로 실제 대화를 나눈 뒤, 그날 오간 내용을 그대로 채운다.
> **채우기 전까지 이 문서는 사료가 아니라 질문지다.** 추측으로 채우지 않는다.

## 논점 질문 (답변란 비어 있음)

1. 협회 사이트에서 대회 결과를 확인할 때 구체적으로 무엇이 불편했는가? 어떤 상황에서, 몇 번쯤 겪었는가?
   -
2. 그 불편을 그때는 어떻게 해결하고 있었는가? (직접 기록, 사진 촬영, 코치에게 문의 등)
   -
3. "직접 만들어보자"는 이야기가 나온 시점과 계기는 무엇이었는가?
   -
4. 처음에 만들려고 했던 것은 지금의 형태였는가, 더 작은 것이었는가?
   -
5. 만들기로 할 때 "이것만 되면 성공"이라고 생각한 최소 조건이 있었는가?

# 디자인 방향 결정 — 스포츠 데이터 브랜드

> ✅ **실제 기록.** 개발 세션에서 실제로 내려진 결정을 사실 그대로 기록한 것이다.
> 공동연구자(박소윤)와의 도메인 논의가 아니라, 개발 도구를 쓰며 내린 구현·디자인 결정이다.

## 논의 배경

2026-07-30 자동 디자인 감사에서 핵심 페이지가 **40점 만점에 26점**을 받았다. 지적된 문제는 다음과 같다.

- 전체 인상이 "제네릭 어드민 대시보드 같다"
- 서체가 Inter 하나뿐이라 화면 어디에도 성격이 없음
- 타입 계층이 플랫함 — 제목과 본문의 위계가 약해 무엇이 중요한지 읽히지 않음

펜싱 기록 데이터를 다루는 서비스인데도 화면에서 그 성격이 드러나지 않는다는 것이 문제의 핵심이었다.

## 논의 내용

세 가지 방향이 선택지로 제시되었다.

| 선택지 | 내용 | 성격 |
|--------|------|------|
| (a) **스포츠 데이터 브랜드** | 숫자·스코어에 콘덴스드 디스플레이 서체를 도입해 기록 데이터의 성격을 전면에 세움 | 중간 규모 변경 |
| (b) 정제된 미니멀 | 서체를 추가하지 않고 기존 서체의 웨이트 대비만으로 위계를 만듦 | 최소 변경 |
| (c) 과감한 리프레시 | 새 비주얼 월드를 정의해 전면 교체 | 최대 변경 |

## 결정 사항

**(a) 스포츠 데이터 브랜드**를 채택했다.

## 결정 근거

기록 데이터가 이 서비스의 본체이므로, 숫자가 화면에서 주인공이 되는 방향이 서비스 성격과 일치한다고 판단했다. (b)는 감사에서 지적된 "성격 없음" 문제를 해소하지 못하고, (c)는 이미 운영 중인 서비스를 전면 교체하는 비용이 컸다.

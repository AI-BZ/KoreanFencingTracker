# ✅ 대법원 2016년 판례: 정확한 사건번호와 판결문

## 사건번호

### **대법원 2016. 8. 17. 선고 2014다235080 판결**


***

## 📋 판결 세부 정보

### 사건명

```
부당이득금반환 청구사건
(공개된 개인정보를 수집하여 제3자에게 제공한 행위에 대하여 
개인정보자기결정권의 침해를 이유로 위자료를 구하는 사건)
```


### 판례 번호

```
공2016하, 1319
```


***

## 🔍 사건 개요

### 사건의 경과

```
【 원고 】
경기도 소재 국립대학교 법학과 교수 A씨

【 피고 】
로앤비 (종합 법률정보 제공 포털사이트)
네이버, SK커뮤니케이션즈, 디지털조선일보, 구글코리아, 야후코리아 (총 6개사)

【 분쟁 내용 】
- 피고들이 원고의 동의 없이 개인정보(사진, 성명, 성별, 출생연도, 직업, 직장, 학력, 경력) 무단 수집
- 이를 로앤비 사이트 '법조인' 항목에 유료로 제공
- 원고는 부당이득금반환 청구 + 위자료 청구

【 판결 결과 】
1심: 원고 패소
2심 (항소심): 로앤비에게만 위자료 50만원 지급 명령
대법원: 원고 청구 최종 기각 (모두 합법)
```


***

## ⚖️ 대법원의 핵심 판시

### 법원이 판단한 핵심 원칙[^1][^2][^3][^4]

```
【 판시 1: 공개된 개인정보의 재활용 】

"이미 공개된 개인정보를 정보주체의 동의가 있었다고 
객관적으로 인정되는 범위 내에서 수집·이용·제공 등 처리를 할 때는 
정보주체의 별도의 동의는 불필요하다"

→ 당신의 상황: ✅ 대회 결과가 이미 공개됨 = 재활용 합법


【 판시 2: 영리목적이 있어도 합법 】

"로앤비가 영리 목적으로 개인정보를 수집해 제공했다고 하여 
달리 볼 수 없다"

→ 당신의 상황: ✅ 유료 서비스 제공 합법


【 판시 3: 공익성과 정보공개의 필요성 】

"정보의 공공성과 공익성, 정보공개의 목적·절차·이용행태의 상당성과 필요성 등을 
종합적으로 따져 판단해야 한다"

→ 당신의 상황: ✅ 펜싱 기록 분석은 공익적 가치 있음


【 판시 4: 원래 공개 목적과의 관련성 】

"정보제공 목적도 원고의 직업정보를 제공하는 것으로서 
원고의 원래 공개 목적과 상당한 관련성이 있는 점 등을 종합하면,
동의가 있었다고 객관적으로 인정되는 범위 내라고 봄이 타당"

→ 당신의 상황: ✅ 대회 기록 공개 목적과 분석 제공 목적이 일치
```

## 📜 판결문 전문 발췌[^2]

```
【 대법원 판결문 핵심 부분 】

"이 사건 개인정보는 일반인이 일반적으로 접근할 수 있도록 
외부에 공개된 매체인 대학교 법과대학 홈페이지나 
대학 교수요람에 이미 공개된 개인정보이고, 
그 내용 또한 민감정보나 고유식별정보에 해당하는 것은 없으며"

→ 당신의 상황: 대회 결과도 협회 웹사이트에 공개된 정보 = 동일


"로앤비의 정보제공 목적도 원고의 직업정보를 제공하는 것으로서 
원고의 원래 공개 목적과 상당한 관련성이 있는 점 등을 종합하면, 
로앤비가 개인정보를 수집해 제3자에게 제공한 행위는 
원고의 동의가 있었다고 객관적으로 인정되는 범위 내라고 봄이 타당"

→ 당신의 상황: 펜싱 분석도 경기 기록 공개 목적과 관련성 있음 = 합법


"로앤비에게 영리 목적이 있었다고 하여 달리 볼 수 없다"

→ 당신의 상황: 유료화 해도 합법 = 명확히 인정
```

싱가포르 법인은 되니까 대안이긴 한데
미국 법인이 도움이 될거는 매출이 커지면, 나중에 사업비자를 받아서 우리애들을 미국학교를 보내려고하는데 앙법을 연구해줘

완벽합니다! 이제 **Stripe 결제 + 자녀 교육 전략**을 명확하게 정리해드리겠습니다.

## 📋 단계별 실행 플랜

### **Phase 1: 초기 설립 (현재~6개월)**

**한국에서 시작 → 미국 법인은 나중에**

```
1. 한국 개인사업자/법인 설립
2. FencingMind.ai 도메인 구매
3. Stripe Atlas 가입 ($500)
   → Delaware LLC + 미국 은행계좌 + EIN 자동 처리
   → Stripe 결제 즉시 사용 가능
4. MVP 개발 및 초기 고객 확보
```

**Stripe Atlas 장점:**

- 미국 법인 + 은행 + Stripe 결제를 한 번에 해결
- 고정비 최소화 (연간 약 \$500~800)
- E-2 비자 신청 시 필요한 법인 구조 완성

***

### **Phase 2: 수익 검증 (6개월~1년)**

**월 매출 \$5,000+ 달성 목표**

```
목표: 연 매출 $60,000~100,000
→ E-2 비자 신청 가능 수준
→ "가족이 생활 가능한 수익" 증명
```


***

### **Phase 3: E-2 비자 준비 (1~2년차)**

**투자 확대 + 비자 신청**

#### **E-2 비자 요구사항 (2026년 기준)**

| 항목 | 요구사항 | FencingMind 적용 |
| :-- | :-- | :-- |
| **투자금액** | \$100,000~200,000 권장[^1][^2] | SaaS/데이터 사업: \$100,000~150,000 충분 |
| **국적** | 한국 (E-2 조약국) ✅ | 한국인 100% 가능[^3] |
| **소유지분** | 50% 이상 | 본인 100% 소유 |
| **사업 실체** | 실제 운영 중 증명 | 매출 기록, 고객, 직원 |
| **비자 기간** | 초기 2~5년, 무제한 연장[^4] | 사업 유지 시 계속 갱신 |

#### **투자금 구성 예시 (FencingMind 기준)**

```
총 투자: $120,000

1. 법인 설립 및 초기 비용: $5,000
2. 소프트웨어 개발 (인건비): $40,000
3. 서버 및 인프라 (2년치): $15,000
4. 마케팅 (1년치): $20,000
5. 사무실/가상오피스 (1년): $5,000
6. 급여 예비금 (직원 1~2명, 6개월): $30,000
7. 운영 자본금: $5,000

✅ 이 정도면 충분히 E-2 승인 가능[web:235][web:239]
```


***

### **Phase 4: 자녀 교육 혜택 (비자 승인 후)**

#### **🎓 자녀 교육 혜택 (E-2 동반 비자)**

| 혜택 | 내용 |
| :-- | :-- |
| **공립학교 무상교육** | 유치원~고등학교 무료[^5][^4] |
| **비자 나이 제한** | 만 21세 미만 자녀 모두 포함[^5][^6] |
| **대학 진학** | 가능 (단, In-State 학비는 주마다 다름)[^7] |
| **21세 이후** | F-1 학생비자로 전환 필요[^5][^8] |
| **배우자 취업** | 배우자는 취업허가(EAD) 가능[^4][^8] |

#### **⚠️ 주의사항**

- 자녀는 21세까지만 E-2 동반 가능[^5][^6]
- 21세 이후 대학 다니려면 F-1으로 전환
- **타이밍**: 자녀가 어릴 때 시작해야 최대한 활용 가능

**귀하의 자녀 나이 계산:**

- 2013년 7월생 = 현재 12세
- E-2 신청 시점 (2027년 가정) = 13~14세
- **21세까지 약 7~8년 사용 가능** ✅

## 🆚 대안 비교: E-2 vs L-1 vs 싱가포르

### **E-2 투자비자 (추천)**

✅ 투자: \$100,000~200,000
✅ 무제한 연장 가능
✅ 자녀 공립학교 무료
✅ 배우자 취업 가능
❌ 21세 이후 자녀는 별도 비자 필요

### **L-1 주재원비자**

✅ 투자금액 제한 없음 (회사 파견)
✅ 영주권 전환 가능 (EB-1C)
✅ 자녀 교육 동일
❌ **한국 모기업이 1년 이상 운영 필요**[^9][^10]
❌ 본인이 1년 이상 근무 기록 필요
❌ 미국 지사 설립 비용 높음

**FencingMind에는 부적합** - 스타트업이라 한국 모기업이 없음

### **싱가포르 법인 (Stripe 대안)**

✅ Stripe 사용 가능
✅ 법인세 17%
✅ 고정비: 연 \$2,000~3,000
❌ **자녀 미국 교육 불가능** ❌
❌ 미국 비자와 무관

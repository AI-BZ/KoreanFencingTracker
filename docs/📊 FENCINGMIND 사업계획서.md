**미션:**
펜싱 선수, 코치, 클럽, 팬들에게 데이터 기반 인사이트를 제공하여 펜싱 생태계의 성장과 발전을 촉진한다.

***

## 1. 사업 개요

### 1.1 시장 기회

**글로벌 펜싱 시장 현황:**

- 전 세계 FIE 등록 선수: 약 150,000명
- 올림픽 정식 종목 (높은 인지도)
- 데이터 인프라 부재: 분산된 정보, 통합 플랫폼 없음
- 디지털 전환 부족: 대부분 수기 관리 또는 구식 시스템

**핵심 문제점:**

- 선수/코치: 경기 분석 데이터 부족
- 클럽: 회원 관리 시스템 열악
- 학부모: 자녀 성장 추적 어려움
- 펜싱 용품: 신뢰할 정보 없음

**FencingMind의 해결책:**
통합 데이터 플랫폼으로 펜싱 생태계의 모든 정보를 연결

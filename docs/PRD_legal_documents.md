## 1. 목적

FencingMind 서비스 운영에 필요한 법적 문서(이용약관, 개인정보처리방침 등)를 작성하고,
회원가입 시 적법한 동의 수집, 사이트 전체에서 문서 접근성 확보, 동의 이력 감사(audit) 시스템을 구축한다.

### 1.1 현재 문제점

| 문제 | 심각도 | 설명 |
|------|--------|------|
| `/terms`, `/privacy` 404 | CRITICAL | 회원가입 폼에 링크가 있지만 실제 페이지 없음 |
| 서버사이드 동의 검증 없음 | CRITICAL | HTML `required`만 의존, 서버에서 체크하지 않음 |
| `consent_logs` 테이블 없음 | HIGH | 동의 시점/버전/IP 기록 불가 (PIPA 위반) |
| 국외이전 동의 없음 | HIGH | Supabase(미국) 데이터 저장에 대한 동의 미수집 |
| 풋터에 법적 링크 없음 | HIGH | 모든 페이지에서 접근 가능해야 함 (PIPA 제30조 2항) |
| CPO(개인정보 보호책임자) 미지정 | MEDIUM | 방침에 기재 필요 |

### 1.2 법적 근거

| 법률 | 조항 | 요구사항 |
|------|------|----------|
| 개인정보보호법(PIPA) | 제30조 | 개인정보처리방침 작성/공개 의무 |
| PIPA | 제15조, 제22조 | 동의 수집 시 고지사항 4가지 |
| PIPA | 제17조 | 제3자 제공 시 별도 동의 |
| PIPA | 제22조의2 | 14세 미만 법정대리인 동의 |
| PIPA | 제28조의8 | 국외이전 동의/고지 |
| 약관규제법 | 제3조 | 약관의 명시/설명 의무 |
| 전자상거래법 | 제10조 | 이용약관 게시 의무 |

### 3.2 FencingMind 특화 조항

**제8조 (대회 데이터 이용)**:
```
1. 회사는 대한펜싱협회(fencing.sports.or.kr)가 공개한 대회 결과 데이터를
   수집, 가공하여 통합 데이터 서비스를 제공합니다.
2. 선수 데이터(이름, 소속, 대회 성적)는 이미 공개된 정보로서,
   대한펜싱협회 웹사이트와 동일한 수준으로 표시됩니다.
3. 통합 프로필, 상세 분석 등 부가 기능은 회원가입 또는 구독이 필요합니다.
4. 선수 본인은 자신의 데이터에 대해 다음 권리를 행사할 수 있습니다:
   a. 데이터 정정 요청
   b. 통합 프로필 비공개 전환 (opt-out)
   c. 선수 연결(Player Claim)을 통한 데이터 관리
```

**제9조 (클럽 관리 서비스)** — 미성년자 관련:
```
1. 클럽 서비스에서 미성년 회원(14~18세)의 출석, 수업 기록은
   보호자(학부모 회원)에게 공유됩니다.
2. 코치가 미성년 선수에게 메시지를 발송할 경우,
   보호자에게도 동일 내용이 전달됩니다.
```

| 국외이전 | 없음 | **신규** `[필수]` — Supabase 미국 서버 |
| 추가정보 수집 | 없음 (전화/생일이 폼에 있지만 동의 분리 안됨) | **신규** `[선택]` — 전화번호, 생년월일 |
| 인라인 고지 | 없음 | 각 동의 항목 아래 수집항목/목적/기간 표시 |

### 5.3 서버사이드 동의 검증

현재 `POST /auth/register`에서 `terms`, `privacy` 파라미터를 받지 않는 문제 수정:

```python
# auth/router.py - register_member() 변경
@router.post("/auth/register")
async def register_member(
    request: Request,
    token: str = Form(...),
    full_name: str = Form(...),
    # ... 기존 필드 ...
    # 동의 항목 (서버에서 반드시 검증)
    terms_consent: bool = Form(False),
    privacy_consent: bool = Form(False),
    overseas_consent: bool = Form(False),
    optional_privacy_consent: bool = Form(False),
    marketing_consent: bool = Form(False),
    promotional_consent: bool = Form(False),
):
    # 필수 동의 검증
    if not all([terms_consent, privacy_consent, overseas_consent]):
        raise HTTPException(status_code=400, detail="필수 동의 항목을 모두 체크해주세요")

    # ... 회원 생성 ...

    # consent_logs에 기록
    consent_entries = [
        {"consent_type": "terms_of_service", "agreed": True},
        {"consent_type": "required_privacy", "agreed": True},
        {"consent_type": "overseas_transfer", "agreed": True},
        {"consent_type": "optional_privacy", "agreed": optional_privacy_consent},
        {"consent_type": "marketing", "agreed": marketing_consent},
        {"consent_type": "promotional", "agreed": promotional_consent},
    ]
    for entry in consent_entries:
        supabase.table("consent_logs").insert({
            "member_id": member_id,
            "consent_type": entry["consent_type"],
            "agreed": entry["agreed"],
            "consent_version": "1.0",
            "ip_address": request.client.host,
            "user_agent": request.headers.get("user-agent", ""),
        }).execute()
```

### 5.4 선택 정보 미동의 시 처리

`optional_privacy_consent = False`일 때:
- 전화번호, 생년월일 입력란을 disabled 처리 (JS)
- 서버에서도 해당 값 무시 (None으로 저장)
- 기존에 입력된 값이 있다면 DB에서 NULL로 업데이트

```sql
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    member_id UUID NOT NULL REFERENCES members(id) ON DELETE CASCADE,

    )),
    agreed BOOLEAN NOT NULL,
    consent_version VARCHAR(10) NOT NULL DEFAULT '1.0',
    ip_address INET,
    user_agent TEXT,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_consent_logs_member ON consent_logs(member_id);
CREATE INDEX idx_consent_logs_type ON consent_logs(consent_type, agreed);

-- 2. legal_documents 테이블 (버전 관리)
CREATE TABLE IF NOT EXISTS legal_documents (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),

        'terms',      -- 이용약관

    )),

    content_ko TEXT NOT NULL,         -- 한국어 원문 (Markdown)
    content_en TEXT,                  -- 영어 번역 (선택)
    effective_date DATE NOT NULL,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    created_by UUID REFERENCES members(id),
    UNIQUE(doc_type, version)
);

-- 3. members 테이블에 overseas_consent 컬럼 추가
ALTER TABLE members ADD COLUMN IF NOT EXISTS overseas_transfer_consent BOOLEAN DEFAULT FALSE;
ALTER TABLE members ADD COLUMN IF NOT EXISTS optional_privacy_consent BOOLEAN DEFAULT FALSE;
```

```markdown
# FencingMind 이용약관

**시행일**: 2026-03-01
**버전**: 1.0

## 제1조 (목적)

본 약관은 FencingMind LLC(이하 "회사")가 운영하는 FencingMind 서비스

   - Community 서비스: 펜싱 커뮤니티 포럼
   - Shop 서비스: 펜싱 용품 쇼핑
   - Blog 서비스: 펜싱 콘텐츠
   - Analytics 서비스: AI 경기 분석
   - Account 서비스 (account.fencingmind.ai): 통합 계정 관리
2. "회원"이란 본 약관에 동의하고 서비스에 가입한 자를 말합니다.
3. "선수 데이터"란 대한펜싱협회가 공개한 대회 결과, 선수 성적 등의

## 제3조 (약관의 효력 및 변경)

1. 본 약관은 서비스 화면에 게시하거나 기타 방법으로 회원에게
   공지함으로써 효력이 발생합니다.
2. 회사는 관련 법령에 위배되지 않는 범위에서 약관을 변경할 수 있습니다.
3. 약관 변경 시 적용일 7일 전부터 서비스 내 공지합니다.
   회원에게 불리한 변경 시 30일 전부터 공지하며, 이메일 또는
   서비스 내 알림으로 개별 통지합니다.
4. 변경된 약관에 동의하지 않는 회원은 서비스 이용계약을
   해지(탈퇴)할 수 있습니다. 공지 후 30일 이내 거부 의사를
   표시하지 않으면 동의한 것으로 봅니다.

## 제4조 (서비스 내용)

1. 회사는 다음의 서비스를 제공합니다:
   가. 펜싱 대회 데이터 조회 및 분석
   나. 선수 프로필 및 랭킹 정보
   다. 클럽/학교 회원 관리 (출석, 수업, 비용)
   라. 펜싱 커뮤니티 (포럼, Q&A)
   마. 펜싱 용품 쇼핑
   바. 펜싱 콘텐츠 (기술 가이드, 리뷰)
   사. AI 경기 분석
2. 각 서비스는 무료/유료 등급으로 구분되며,
   유료 서비스의 이용 조건은 해당 서비스 페이지에서 안내합니다.

## 제5조 (이용계약 체결)

1. 이용계약은 회원이 되려는 자가 본 약관과 개인정보처리방침에
   동의한 후 회원가입을 신청하고, 회사가 이를 승낙함으로써
   체결됩니다.
2. 회원가입은 카카오, Google 등 소셜 로그인(OAuth)을 통해
   진행됩니다.
3. 회사는 다음 각 호에 해당하는 가입 신청을 거부할 수 있습니다:
   가. 실명이 아닌 허위 정보로 신청한 경우
   나. 타인의 정보를 도용한 경우
   다. 이전에 약관 위반으로 이용이 제한된 경우
   라. 기타 관련 법령에 위반되는 경우

## 제6조 (회원의 의무)

1. 회원은 다음 행위를 하여서는 안 됩니다:
   가. 가입 시 허위 정보 제공
   나. 타인의 정보 도용
   다. 서비스에서 얻은 정보를 회사의 동의 없이 상업적으로 이용
   라. 회사 또는 제3자의 저작권, 지적재산권 침해
   마. 서비스의 안정적 운영을 방해하는 행위
   바. 불법적 목적으로 서비스를 이용하는 행위
2. 회원은 관련 법령, 본 약관, 이용 안내 및 서비스와 관련하여

## 제7조 (회사의 의무)

1. 회사는 관련 법령과 본 약관을 준수하며, 안정적으로

2. 회사는 회원의 개인정보를 보호하기 위해 개인정보처리방침을

3. 회사는 서비스 이용과 관련한 회원의 불만이나 피해 구제 요청을

## 제8조 (대회 데이터 이용)

1. 회사는 대한펜싱협회(fencing.sports.or.kr)가 공식적으로 공개한

2. 선수 데이터(이름, 소속, 대회 성적)는 대한펜싱협회 웹사이트에서

3. 통합 프로필, 상대 전적, 성과 분석 등 부가 기능은 회원가입

5. opt-out 요청 시, 회사는 요청 접수 후 10일 이내에 처리합니다.

   가. 국내: 신용카드, 체크카드, 계좌이체, 간편결제(카카오페이,
       네이버페이, 토스 등)
   나. 해외: 국제 신용카드, 해외 결제 서비스
2. 구독 서비스는 설정된 주기(월/연)에 따라 자동 갱신되며,

   결제 예정일 7일 전에 이메일 또는 서비스 내 알림으로 안내합니다.
3. 구독 해지 시 이미 결제된 기간의 잔여 기간은 계속 이용 가능하며,
```

```markdown
# FencingMind 개인정보처리방침

**시행일**: 2026-03-01
```
